A program that writes one sentence about the best meal ever had — ayam goreng so crisp it was heard before it was tasted, at a Yogyakarta warung, sambal so hot the tears got blamed on the sunset — to `/output/entry.txt`. One sentence, 162 characters, deterministic: the same bytes on every run. Built by an AI agent for make.fun's "The Best Meal You Ever Had" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
